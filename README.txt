OctoFuel landing page files

Files:
- index.html
- styles.css

How to preview:
Double-click index.html in your browser.

Important:
The contact form currently opens the visitor's email app and sends to hello@octofuel.in.
For a proper form that stores submissions, use Formspree, Basin, or Google Forms later.

How to upload free:
1. Create a GitHub account.
2. Create a new repository named octofuel-landing.
3. Upload index.html and styles.css.
4. Go to Settings > Pages.
5. Source: Deploy from branch.
6. Branch: main, folder: /root.
7. Save.

To connect octofuel.in:
1. In GitHub Pages, add custom domain: octofuel.in.
2. In GoDaddy DNS, add GitHub Pages A records:
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
3. Add CNAME for www pointing to your-github-username.github.io
4. Wait for DNS to update.
